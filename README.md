# ArchBrowser

Приватный браузер на Chromium (Electron) с блокировкой слежки, встроенным VPN на
Xray-core и поддержкой расширений Chrome.

## Быстрый запуск

- `start.bat` — обычный запуск (на несколько секунд появится окно консоли).
  Если `node_modules` нет, скрипт запускает готовый portable из `dist`.
- `ArchBrowser.vbs` — тихий запуск без консоли (тоже умеет запускать portable).
- `npm start` — запуск из терминала.
- `dist\ArchBrowser-1.0.0.2-setup.exe` — установщик Windows (ярлык в меню «Пуск», удаление через «Приложения»).

Требуется Windows 10/11 x64. Node.js и другие зависимости для запуска **не нужны**:
Electron и Xray уже лежат в папке проекта.

Если браузер не открывается, причина записывается в
`%APPDATA%\ArchBrowser\startup.log`. Встроенный OpenCode при этом ни при чём:
он необязателен, запускается только по кнопке и не мешает старту.

Portable-версия распаковывается в `%TEMP%` (обычно диск `C:`) и требует
примерно 600 МБ свободного места. Если системный диск переполнен, portable
закрывается без окна — освободите место или запустите
`dist\win-unpacked\ArchBrowser.exe` (он работает без распаковки).

## Возможности

### Защита от слежки
- Блокировка рекламы и трекеров по объединённому списку (~249 000 доменов),
  включая CNAME-трекеры.
- Встроенный **uBlock Origin 1.75.0** с фильтрами EasyList/EasyPrivacy и
  косметической фильтрацией; настройки открываются шестерёнкой в разделе
  «Расширения». Он дополняет собственный доменный блок-лист.
- Реклама на «первопартийных» путях (`yandex.ru/ads/…`, `yastatic.net/…adfox…`,
  `google.*/pagead/…`) отсекается ещё и на уровне сетевых запросов.
- Блокировка сторонних cookie (`blockThirdPartyCookies`).
- HTTPS-only: небезопасные переходы по http поднимаются до https.
- Очистка трекинговых параметров (`utm_*`, `fbclid`, `gclid` и др.) при переходах.
- Обрезка `Referer` до источника.
- Подмена Canvas/WebGL/Audio/ClientRects/часового пояса/языка и других
  фингерпринт-поверхностей (отключается в настройках).
- Защита от утечек WebRTC (только проксированный UDP).
- DoH (Cloudflare по умолчанию), отключение Privacy Sandbox/Topics/Fledge,
  `no-pings`, отключение телеметрии Chromium.
- Приватные окна работают в отдельной непостоянной сессии; расширения туда не
  загружаются.

### VPN (Xray-core)
- Поддержка ссылок: `vless://`, `vmess://`, `trojan://`, `ss://`, `socks://`,
  `http://`, `https://`.
- VLESS + Reality/TLS, WS, gRPC, HTTP/2, XHTTP, TCP/HTTP-маскировка.
- Импорт серверов вставкой ссылки/списка, импорт подписок по URL.
- Локальные SOCKS5 и HTTP inbound-порты (по умолчанию 10808/10809, при занятости
  подбираются свободные), трафик браузера направляется через SOCKS5.
- Проверка задержки серверов, журнал Xray, автоматическое подключение при старте
  (опция).
- Приватные окна используют тот же VPN-туннель, но собственную сессию.
- Исключения `.ru` и `.рф`: эти сайты по умолчанию идут напрямую. Если какой-то
  из них напрямую не отвечает, браузер сам повторяет загрузку через туннель.

### Оформление
- Светлый, тёмный или системный режим выбирается отдельно от темы; у каждой
  темы есть оба варианта.
- Темы: «Оригинальная» (по умолчанию, нейтральная без акцентных цветов),
  «Акцентная» (та же тема с системным акцентом), киберпанк (жёлтый и голубой),
  неон (голубой слева, розовый справа), Umbrella Corp (со своим логотипом на
  новой вкладке), золото, серебро, AMOLED (истинно чёрные поверхности),
  Silent Hill (туман и ржавчина), новый год, рождество, зима, лето, осень,
  весна.
- Праздничные темы названы по праздникам: День всех влюблённых, День
  защитника Отечества, Международный женский день, Праздник Весны и Труда,
  День Победы, День России, День народного единства, Хэллоуин. На новой
  вкладке у каждой свой символ и обратный отсчёт, а не только ёлка.
- Автотема праздников: включается за 7 дней до даты, после праздника
  отключается на следующий день. Новогодняя тема остаётся по 6 января,
  затем возвращается прежняя. Отключается в настройках.
- В новогодней теме новая вкладка украшается ёлкой с гирляндой и обратным
  отсчётом; у остальных праздников — свой символ (крест на Рождество, флаг,
  сердце, тыква и т. д.).
- Акцентный цвет берётся из Windows (в темах — свой).

### RSS-ленты
- Подписки на RSS и Atom добавляются в настройках: адрес ленты, переименование
  и удаление. Ленты подтягиваются по расписанию (15 минут – 3 часа).
- Заголовки из лент показываются внизу новой вкладки.

### Режим чтения
- Кнопка в адресной строке и `Alt+R` оставляют только текст статьи: без
  баннеров, сайдбаров и рекламы. Кнопка «Выйти из режима чтения» — на странице.

### Уведомления с сайтов
- Всплывающие сообщения разрешаются для всех сайтов, только для сайтов из
  списка или запрещаются — режим выбирается в настройках.

### Плеер и пульт медиа
- Плеер аудиофайлов с компьютера: кнопка с нотой на панели инструментов,
  плейлист, перемотка, поддержка mp3/m4a/aac/ogg/opus/wav/flac/wma.
- Пульт появляется только при воспроизведении; его положение (сверху или
  снизу окна) выбирается в настройках. Кнопка закрытия останавливает музыку и
  прячет пульт. Если трек закончился, пульт тоже скрывается.
- Повтор: трек, весь плейлист или выключен. Перемешивание отдельной кнопкой.
- Кнопка «Назад» помнит до 1000 последних композиций и возвращает именно
  предыдущую, даже после перезапуска.
- Панель управления воспроизведением управляет и локальными файлами, и
  видео/звуком на открытой странице (Media Session API).

### Загрузки
- Файлы сохраняются в системную папку «Загрузки» или в выбранную в настройках.
- Режим «Спрашивать каждый раз» показывает системный диалог сохранения.
- Системные уведомления о начале, завершении и ошибках загрузки.
- После завершения браузер предлагает открыть файл или показать его в папке.
- Панель «Загрузки» (`Ctrl+J`): прогресс, скорость, пауза, продолжение, отмена,
  открытие файла и переход к нему в Проводнике.
- Прогресс также виден в системном трее и на кнопке приложения.

### BitTorrent-клиент
- Файлы `.torrent` и magnet-ссылки: magnet из адресной строки сразу
  открывается в клиенте.
- При добавлении каждого нового торрента браузер спрашивает папку для
  сохранения (последняя папка запоминается как начальная в диалоге).
- Ссылки `magnet:` на сайтах (например, значок магнита на rutor.info)
  открываются во встроенном клиенте, а не игнорируются браузером. Скачанный
  `.torrent` файл предлагается сразу добавить в BitTorrent-клиент.
- В поле «Добавить торрент» работает контекстное меню: вырезать, копировать,
  вставить, выделить всё.
- Поддержаны трекеры HTTP/HTTPS и UDP, протокол peer-to-peer, проверка
  частей по SHA-1 и сохранение в выбранную папку.
- Для magnet-ссылок без трекеров работает DHT; дополнительно используются
  публичные HTTPS-трекеры, если UDP-трафик трекеров блокируется.

### Дополнительные функции
- В настройках есть переключатели для всех возможностей: прототип при
  загрузке, режим чтения, пресеты таймера, локальный плеер, пульт медиа,
  BitTorrent-клиент и всплывающие сообщения.

### Браузер
- Вкладки (`WebContentsView`), приватные окна, восстановление/закрытие вкладок.
- Разделённый экран: обе половины показываются одной вкладкой с двумя
  под-вкладками; закрытие любой половины завершает разделённый просмотр.
- Подсказки адресной строки открываются отдельным окном поверх страницы —
  панель браузера при этом не сдвигается.
- Внизу вкладки — тонкая полоска прогресса загрузки страницы.
- Уведомления и сообщения об ошибках показываются отдельным окном поверх
  страницы, поэтому их не перекрывает содержимое сайта.
- Если сервер не ответил за 30 секунд, вместо пустого экрана открывается
  страница «Страница не отвечает» с кнопками «Повторить» и «Открыть через VPN»;
  ошибки загрузки (нет DNS, соединение сброшено) показываются так же.
- Положение вкладок выбирается в настройках: сверху, снизу, слева или справа.
  При боковом положении вкладки образуют вертикальную панель, при нижнем —
  строку над нижней границей окна.
- Перетаскивание вкладок для изменения порядка и контекстное меню вкладки:
  закрыть, закрыть другие/справа, дублировать, скопировать адрес, добавить в
  закладки, открыть в разделённом экране.
- Разделённый экран, как в Chrome: активная вкладка и вторая вкладка рядом.
  Включение — кнопка на панели, пункт меню вкладки или `Ctrl+Shift+E`. Клик по
  половине переключает фокус, но половины не меняются местами; новая вкладка
  заменяет только активную половину. Кнопка закрытия разделённого экрана
  возвращает обычный режим.
- Анимации открытия и закрытия вкладок: новая вкладка «раскрывается», закрытая
  схлопывается с уменьшением, сдвигом и размытием, соседние плавно сдвигаются.
  Анимация видна и при быстром закрытии нескольких вкладок.
- Вкладки встроены в заголовок окна; при верхнем/нижнем положении строка
  вкладок занимает свою полосу, при боковом — отдельную вертикальную панель.
  Кнопки окна — системные.
- Главное меню (гамбургер) открывается нативным меню Windows и всегда
  отображается поверх страниц — в том числе при нижних/боковых вкладках и в
  разделённом экране.
- Светлый/тёмный режим выбирается отдельно от темы: «Как в системе» следует за
  Windows, либо светлый/тёмный принудительно. Акцентный цвет берётся из
  системных настроек Windows и применяется к интерфейсу и новой вкладке.
  Тёмные поверхности нейтральные, как в Проводнике Windows 11, без синего
  оттенка; синий остаётся только акцентным цветом.
- Значок ArchBrowser — серебряный древний глаз с шестью крыльями на прозрачном
  фоне; он же используется в панели задач и на странице «О программе».
  В режиме исходников иконка встраивается прямо в `electron.exe` скриптом
  `scripts/patch-electron-icon.js` (запускается после `npm install`), поэтому
  на панели задач отображается значок ArchBrowser, а не Electron. В собранной
  версии иконка вшита в `ArchBrowser.exe`. Если Windows закешировала старую
  иконку, открепите и снова закрепите кнопку на панели задач.
- Загрузки показывают прогресс в системном трее (кольцо вокруг значка) и на
  кнопке приложения в панели задач; индикаторы сбрасываются после завершения
  или отмены загрузки.
- Telegram: встроенная боковая панель с `web.telegram.org`, вход сохраняется,
  показывается счётчик непрочитанных. Открыть/закрыть — кнопка в панели или
  `Ctrl+Shift+M`.
- Омнибокс: поиск, подсказки из истории и закладок, поисковые системы
  DuckDuckGo/Startpage/Brave/Google/Яндекс. Контекстное меню — как в Chrome:
  отменить/вернуть, вырезать, копировать, вставить, «Вставить и перейти».
- На `arch://newtab` ссылки добавляются и удаляются через контекстное меню
  (правый клик по ссылке или по пустому месту). Кнопок, выскакивающих при
  наведении, больше нет. «Сбросить ссылки» спрашивает подтверждение и
  возвращает стандартный набор.
- Режим чтения подстраивает фон и цвет текста под страницу: на тёмных сайтах
  читалка тоже тёмная.
- Панель закладок под адресной строкой (включается кнопкой в омнибоксе или
  в настройках). Показывает закладки и папки; папка раскрывается выпадающим
  списком прямо на панели. Если закладки не помещаются, появляется кнопка
  «Ещё» с полным меню; элементы не перерисовываются под курсором, поэтому
  подсказки не мигают.
- Закладки можно редактировать (название и адрес) из раздела «Закладки» и из
  контекстного меню на панели.
- Правая часть панели инструментов скрывается одной кнопкой: остаётся
  «Показать» со значком `<`, а кнопка меню находится справа от неё. Все
  действия правой панели (VPN, Telegram, плеер, torrent, расширения,
  загрузки, разделённый экран, поделиться, полный экран, OpenCode, таймер,
  режим чтения, панель закладок) продублированы в главном меню.
- В полноэкранном режиме панели не скрываются: вкладки, адресная строка,
  включённая панель закладок и пульт музыки остаются на месте. Это одинаково
  предсказуемо на Windows, macOS и Linux.
- На macOS панели используют Liquid Glass — нативное размытие фона и
  полупрозрачные поверхности; отключается в настройках оформления.
- Папки в закладках: создание, переименование, вложенность и перемещение
  закладок между папками — в разделе «Закладки».
- История, закладки, загрузки, поиск по странице (Ctrl+F), масштаб, полноэкранный
  режим, контекстное меню, горячие клавиши.
- Расширения Chrome: папка `%APPDATA%\ArchBrowser\extensions`, включение,
  отключение и удаление из интерфейса.
- Закрытие окна полностью завершает браузер: фоновых процессов не остаётся.
- При загрузке страницы вместо белого экрана показывается прототип с эффектом
  боке в акцентных цветах.

### Пароли
- Хранилище паролей целиком зашифровано: без мастер-пароля ключ хранится в
  Credentials Manager средствами ОС (DPAPI в Windows), с мастер-паролем —
  AES-256-GCM с ключом от scrypt.
- Контейнер подписан HMAC-SHA256: подмена или порча файла обнаруживается,
  а не приводит к выдаче мусора.
- Мастер-пароль задаётся в настройках; автоблокировка по бездействию
  (5/15/30/60 минут). Пока хранилище заблокировано, список паролей скрыт.
- Пароли читаются из профилей Chrome/Edge/Brave/Vivaldi/Opera/Firefox, а также
  импортируются из CSV-файла, который браузер отдаёт при экспорте.

### OpenCode
- Встроенный ИИ-агент OpenCode: веб-интерфейс открывается прямо в браузере
  отдельной панелью и работает с выбранной папкой проекта.
- Браузер сам поднимает `opencode serve` на локальном порту и выполняет вход
  по коду подключения — вводить пароль не нужно.
- Используется CLI из настольного приложения OpenCode или установленный
  `opencode`. Если CLI не найден, кнопка OpenCode скрывается, а в настройках
  появляется подсказка. **На запуск браузера это не влияет**: OpenCode
  необязателен, ничего не запускает при старте и загружается лениво.
- Кнопка в панели инструментов, папка проекта выбирается в настройках.

## VPN: как подключить

1. Откройте панель **VPN** (кнопка VPN справа от адресной строки).
2. Вставьте ссылку на сервер или список ссылок и нажмите «Добавить».
   Либо укажите URL подписки — серверы импортируются автоматически.
3. Выберите сервер и нажмите «Подключиться».
4. Кнопка «Проверить» выполняет запрос через туннель.

Ссылку `vless://`, `vmess://`, `trojan://` или `ss://` можно вставить прямо в
адресную строку: сервер добавится автоматически, а панель VPN откроется.

Конфигурация Xray генерируется во временную папку профиля
(`%APPDATA%\ArchBrowser\vpn\config.json`) и запускается как отдельный процесс.
Список серверов и подписок хранится в `%APPDATA%\ArchBrowser\vpn.json`.

> VPN-протоколы не шифруют трафик сами по себе: безопасность обеспечивает
> выбранный сервер. Используйте только доверенные конфигурации и соблюдайте
> законодательство своей страны.

## Антибот-проверки (Cloudflare, DDoS-Guard)

Сайты за Cloudflare (например, rutracker.org) могут показать страницу
«Выполнение проверки безопасности». В обычном Chrome проверка проходит сама,
а Chromium внутри Electron антибот-системы нередко принимают за бота — особенно
при подключении через VPN.

Что делает браузер:

- отдаёт настоящие Client Hints (`Sec-CH-UA` с брендом Google Chrome,
  `navigator.userAgentData`), согласованные `Accept-Language`,
  `navigator.language` и `window.chrome.csi/loadTimes`;
- если через 6 секунд на странице всё ещё видна проверка, показывает
  предупреждение с кнопками «Открыть в браузере» (по умолчанию), «Повторить» и
  «Закрыть»;
- заглушка загрузки (скелетон) снимается сразу после разбора HTML и в любом
  случае через 12 секунд, поэтому больше не создаёт впечатление вечной загрузки.

Если проверка не проходится — смените VPN-сервер (проверка привязана к IP
выхода) или откройте сайт в браузере по умолчанию.

## Расширения

Скопируйте распакованное расширение (папку с `manifest.json`) в
`%APPDATA%\ArchBrowser\extensions`, затем включите его в разделе
**Расширения**. Поддерживается Manifest V2/V3 в объёме Chromium внутри Electron.

uBlock Origin 1.75.0 уже встроен и устанавливается в профиль при первом
запуске. Шестерёнка рядом с расширением открывает его панель настроек
(`chrome-extension://…/dashboard.html`). В приватные окна расширения не
загружаются.

Дополнительно в поставку включены и автоматически устанавливаются:

- AutoScroll for YouTube Shorts;
- Picture in Picture | PiP — картинка в картинке и A-B;
- Privacy manager;
- Return YouTube Dislike;
- Shazam: поиск названий треков в браузере;
- uBlock Origin Lite;
- User Agent Switcher;
- VK Music Saver;
- VPN для YouTube без ограничений в России;
- Поиск Яндекса;
- HTTPS Everywhere;
- Privacy Badger;
- Volume Master;
- Turn Off the Lights.

uBlock Origin Lite использует Manifest V3 и `declarativeNetRequest`; он
устанавливается рядом с классическим uBlock Origin. Оба блокировщика можно
держать включёнными, но их правила частично пересекаются — для диагностики
удобнее оставлять один. Встроенные расширения обновляются из
`resources/extensions` при изменении их сборочной метки; кеш service worker
сбрасывается автоматически, чтобы не запускались старые скрипты.

Electron не реализует часть Chrome Extension API (`cookies`,
`browsingData`, `privacy`, `webNavigation`, `tabCapture`, `storage.sync` и
некоторые другие). Для встроенных расширений сделаны совместимые заглушки и
замены, поэтому они загружаются и основные функции работают, но отдельные
фирменные возможности (очистка cookie в Privacy manager, контекстное меню
Turn Off the Lights, запись вкладки в Shazam) могут быть недоступны.

## Сборка для macOS

Сборку `.dmg` нужно делать **на macOS**: electron-builder не умеет
собирать macOS-приложение из Windows — нужен сам macOS SDK.

Поэтому в Windows-папке `dist` есть только `.exe`/`win-unpacked`, но **нет
`.dmg`** — он физически не может там появиться. Файл
`ArchBrowser-1.0.0.2-arm64.dmg` создаётся на Mac (или в CI) после запуска
сборки.

Быстрый путь на Mac:

```bash
bash scripts/build-mac-arm64.sh
```

Скрипт сам скачает Xray для Apple Silicon (если его нет) и соберёт DMG.
Либо запустите сборку в GitHub Actions: workflow
`.github/workflows/build-macos-arm64.yml` (Actions → Build macOS ARM64 →
Run workflow), готовый `.dmg` будет в артефактах.

### 1. Что нужно

- **macOS 12 (Monterey) или новее** — Electron 44 требует минимум macOS 11.
- **Node.js 18+** и npm.
- **Xcode Command Line Tools** — ставится командой:

  ```bash
  xcode-select --install
  ```

- **Python 3** (нужен для сборки нативных модулей) — входит в Command
  Line Tools.

Проверка, что всё на месте:

```bash
node -v
npm -v
xcode-select -p
```

### 2. Подготовка проекта

```bash
git clone <адрес репозитория> ArchBrowser
cd ArchBrowser
npm install
```

Если проект переносили с Windows, удалите артефакты сборки, чтобы
electron-builder не взял лишнее:

```bash
rm -rf dist node_modules
npm install
```

### 3. Иконки

В репозитории лежит `assets/icon.icns` (512×512, все размеры). Если иконку
меняли, пересоберите `.icns` через `iconutil` (macOS) или `png2icons`:

```bash
npx png2icons assets/icon.png assets/icon -icns
```

### 4. Сборка

```bash
npm run dist:mac
```

Скрипт запускает `electron-builder --mac --arm64` и собирает образ
только для Apple Silicon. Готовый файл:

```
dist/ArchBrowser-<версия>-arm64.dmg
```

Сборка занимает 10–20 минут: electron-builder скачивает Electron для arm64,
распаковывает Xray-core и расширения, затем сжимает приложение.

### 5. Локальная проверка без установки

```bash
npm start
```

Приложение запустится из исходников. Чтобы проверить именно собранный
образ, откройте `dist/mac-arm64/ArchBrowser.app`.

### 6. Подпись и notarization (для распространения)

Без подписи macOS покажет предупреждение «не открыт из идентифицированного
разработчика». Для публикации нужен Apple Developer ID (платная подписка
$99/год):

```bash
# Подпись
codesign --deep --force --options runtime \
  --sign "Developer ID Application: ИМЯ (TEAMID)" \
  dist/mac-arm64/ArchBrowser.app

# Нотаризация
xcrun notarytool submit "dist/ArchBrowser-<версия>-arm64.dmg" \
  --apple-id "ВАШ_EMAIL" --team-id TEAMID --password "APP-SPECIFIC-PASSWORD"

# Привязка к нотаризации
xcrun stapler staple "dist/mac-arm64/ArchBrowser.app"
```

В `package.json` уже есть готовая секция `build.mac` с
`hardenedRuntime`, `entitlements` (`build/entitlements.mac.plist`) и
`gatekeeperAssess: false` — эти параметры нужны для notarization.

Чтобы electron-builder подписал и отправил на нотаризацию автоматически,
достаточно переменных окружения (сертификат `Developer ID Application`
экспортируется из «Связки ключей» в `.p12`):

```bash
export CSC_LINK="$HOME/certs/DeveloperID.p12"
export CSC_KEY_PASSWORD="пароль-от-p12"
export APPLE_ID="ваш@email"
export APPLE_APP_SPECIFIC_PASSWORD="xxxx-xxxx-xxxx-xxxx"
export APPLE_TEAM_ID="TEAMID"

npm run dist:mac
```

Без этих переменных соберётся неподписанный `.dmg` — он запускается локально,
но на чужом Mac потребует «Продолжить всё равно».

### 7. Частые проблемы

| Симптом | Причина и решение |
| --- | --- |
| `Cannot find module electron` | не выполнен `npm install` в папке проекта |
| `Error: Cannot create dmg` | нет прав на запись в `dist/` или `hdiutil` недоступен |
| `Error: @electron/rebuild failed` | не установлены Command Line Tools и Python 3 |
| `.dmg` не запускается на Intel Mac | сборка только для Apple Silicon (arm64) — это ожидаемо |
| «Приложение повреждено» | не подписано и не notarized; для локального запуска: `xattr -cr /Applications/ArchBrowser.app` |

### 8. Только Apple Silicon

Проект собирается только под arm64 (Apple Silicon). Intel Mac не
поддерживается:

```bash
npx electron-builder --mac --arm64 --publish never
```

### 9. Бинарник VPN под macOS

В `resources/xray/` уже лежит `xray` для Apple Silicon (arm64), рядом с
Windows-сборкой `xray.exe`. Код выбирает файл по платформе. Если нужно
обновить Xray:

```bash
# Xray-core: Xray-macos-arm64-v8a.zip
cp ~/Downloads/xray ~/ArchBrowser/resources/xray/xray
chmod +x resources/xray/xray
```

Проверить архитектуру:

```bash
file resources/xray/xray
# должно быть: Mach-O 64-bit executable arm64
```

Без этого файла приложение соберётся и запустится, но VPN будет недоступен
(кнопка сообщит, что ядро не найдено).

### 10. Если VPN на macOS не подключается

1. Панель **VPN** показывает ошибку Xray — начните с неё.
2. Проверьте, что `resources/xray/xray` — arm64, а не Intel.
3. Снимите карантин с приложения и дайте бинарнику права на запуск:

   ```bash
   xattr -dr com.apple.quarantine /Applications/ArchBrowser.app
   chmod +x "/Applications/ArchBrowser.app/Contents/Resources/resources/xray/xray"
   ```

4. Для распространения подпишите сам Xray перед notarization:

   ```bash
   codesign --force --options runtime \
     --sign "Developer ID Application: ..." resources/xray/xray
   ```

5. Если Xray запускается, но сайты не открываются — проверьте сервер,
   его протокол и задержку кнопкой «Проверить».



- Это не форк Chromium: движок обновляется вместе с Electron. Некоторые
  фирменные функции Chrome (синхронизация, Web Store «из коробки», DRM Widevine)
  отсутствуют.
- Встроенный доменный блокировщик работает на уровне запросов; косметические
  фильтры и расширенные правила обеспечивает встроенный uBlock Origin. Часть
  Chrome Extension API в Electron отсутствует (иконка расширения на панели,
  некоторые события контекстного меню), поэтому настройки uBlock открываются
  из «Расширений».
- Разделённый экран показывает две вкладки фиксированной ширины; перетаскивать
  разделитель между половинами нельзя (в отличие от Chrome). Это ограничение
  `WebContentsView`, а не ошибка отображения.
- Звонки Telegram могут быть недоступны: браузер по умолчанию не выдаёт
  микрофон/камеру сайтам. Переписка и уведомления работают.
- Для сборки portable-версии требуется интернет (electron-builder скачивает
  упаковщик).
- Пароли из профилей Chrome 127+ недоступны: браузер шифрует их «app-bound»,
  ключ привязан к самому Chrome. Для них есть импорт из CSV-файла экспорта.
- Загрузка медиа с сайтов (YouTube, Rutube, VK и другие) удалена: плеер
  работает с локальными файлами, а пульт управляет воспроизведением на
  странице.
- Встроенный OpenCode требует установленного CLI (настольное приложение
  OpenCode подходит) — сам бинарник в поставку не входит, чтобы не раздувать
  размер сборки.
